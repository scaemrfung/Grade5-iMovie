# iMovie Studio — Grade 5 MacBook Unit

A complete **13-lesson** curriculum website with **detailed lesson plans** for teaching iMovie on MacBooks only. Students plan, record, edit, and export polished videos for YouTube and Instagram.

## What's inside

- **13 lessons** (30–45 min each) with click-by-click MacBook steps
- **4 projects** with walkthroughs and 1–4 assessment rubrics
- **Teacher notes** for camera, storage, differentiation, and export

## Live site (GitHub Pages)

After you enable Pages (see below), the site will be at:

`https://YOUR_USERNAME.github.io/imovie-studio/`

## Enable GitHub Pages

1. Open this repository on GitHub
2. Go to **Settings → Pages**
3. Under **Source**, choose **Deploy from a branch**
4. Branch: **main**, folder: **/ (root)**
5. Click **Save**
6. Wait a minute, then open the site URL shown on that page

## Local preview

Open `index.html` in any browser. No build step required.
